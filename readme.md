

# 心情日记 · Mood Diary
作者：陈怡璠

大致风格：一个浅蓝色蕾丝风格的心情日记单页应用，纯前端实现，零构建。**任何人打开页面都能看到大家发布的心情**，并支持给他人的动态点赞。

## ✨ 功能

| 模块 | 说明 |
|------|------|
| 🏠 首页 | 宫崎骏风手绘封面图 + 蕾丝装饰，简洁入口 |
| ✏️ 写动态 | 选择心情（开心/平静/低落/疲惫）、天气，填写文字，可附图（最多 6 张，自动压缩） |
| 🌐 动态 | 查看所有人发布的动态流；支持点赞（一人一赞，可取消）；本人可编辑/删除自己的动态 |
| 📅 心情日历 | 按日期标记自己的心情，可点击格子添加表情 |
| 👤 我的 | 设置昵称/头像/签名，查看统计，导出动态为 txt，清空自己的动态 |

## 🛠 开发线路

- 先使用deepseek做出最基础的大致样式，在使用trae去修改优化来达到最终项目的效果

## 🚀 使用

直接双击打开 `日记.html`

打开后即可使用，所有功能均需联网（动态同步依赖云存储）。

关键设计：

- **设备身份**：每台浏览器首次打开生成 `moodDeviceId`，作为发帖人标识和点赞身份
- **一人一赞**：点赞以设备 ID 存于动态的 `likes` 数组，重复点击切换赞/取消
- **写入安全**：每次同步前先拉取云端最新数据按 id 合并，避免覆盖他人的新动态或点赞
- **图片压缩**：上传前缩至最长边 420px、JPEG 60% 质量，单条动态最多 6 张
- **离线降级**：云端同步失败时自动保存本地，下次打开补传

> ⚠️ **数据隐私**：textdb.online 是开放公共服务，无鉴权，适合朋友间分享使用，**请勿存放隐私内容**。连续 30 天未访问/更新的数据会被自动清理。

## 🔧 自定义

- **换封面图**：修改首页 `<img id="homeCoverImg">` 的 `src`
- **换云端存储 key**：修改 `CLOUD_FEED_KEY` 和 `CLOUD_IMG_PREFIX`（换一个全新的 key 相当于新开一个日记本）
- **改心情/天气选项**：搜索 `moodOptions`、`weatherOptions` 调整

## 📌 注意事项

- 首次打开页面，封面图和动态都依赖联网，可能需要几秒加载
- 同一台浏览器的同一用户，换用不同浏览器/设备会被视为不同人
- 免费云服务偶尔不稳定，若动态无法发布/刷新，刷新页面或稍后重试即可
